## 5-11：已解决

原因：起点被两扇锁门（1,7）、（2,10）围住，唯一不用开门的出路是西南方的一块裂纹石（2,8），它被邻格完全包围，被「地块在黑色迷雾里」的判定误排除，于是起点区域只剩 2 格，钥匙在门后，路线判不可达。

修复：`classify_site` 对已有 ≥2 个已知邻格的位置不再要求周围有迷雾；紫蓝格仍要求在迷雾内（否则蓝色背景会被误认成 19 格紫蓝格，已在 8-11、9-12 上验证并避免）。

结果：新增 3 格裂纹石，5-11 路线为 起点 → 裂纹石 → 战斗 → 战斗 → 裂纹石 → 精英 → 裂纹石 → 联络点 → 事件 → 锈蚀钥匙 → 单行密道 → 密道出口 → 联络点 → 最终战。同一改动还补出另外 22 张图的 1–4 格（多为裂纹石、个别空白格和红色格），共新增 34 格，`maps.json` 现为 2887 格。目测 5-11 与 6-2 的新增格位置正确，其余未逐一检查。

## 第二轮：无图标格与事件数对不上的地图

### 无图标格排查

做法：把全部无图标格（空白、裂纹石、紫蓝、红色）裁成缩略图逐类目测，并枚举「与已识别格相邻、亮度像地面但没被识别」的位置逐个目测。

发现并已修复：

- **漏识别**：3-1、3-2、3-4 各漏 1 个析出点（图标变体，已补模板）；第 7 章的「碎石」型裂纹石（石块间有深色缝隙）漏识别（7-10 ×2、7-11、7-4、7-7、7-6 各 1），7-7 还漏 1 个紫蓝格。这类格子被四周的已知格包围，现在对被 ≥2 个已知格包围的位置放宽判定。
- **误判（已删除）**：把纸张/背景斑块当成格子：空白格 扭曲核心02 ×2、血与沙02 ×1、骑士的愿望03 ×1、8-4 ×1（右侧背景）；裂纹石 骑士的愿望03 ×3、血与沙02 ×1、1-13 ×1；紫蓝格 8-11 ×5、9-12 ×2、9-2 ×1（蓝色背景）。规则：背景斑块没有石面纹理（梯度能量低），裂纹石和紫蓝格要求纹理足够强；第 7 章米色空白格本身很平滑，所以只对低饱和度的平滑块做这条排除。
- 第一轮的 7-7 紫蓝格、5-11 的 3 块裂纹石、34 个补出格，在这一轮的目测中未发现错误。

结果：`maps.json` 现为 2879 格（空白 291、裂纹石 148、红色血肉 61、紫蓝 29）。108 张路线检查仍全部可达。

仍然可疑：6-10 的一格空白（行 5 列 1）是米色平滑块，与第 7 章米色空白格的特征无法区分，保留，未确认；7-6 的一格空白（行 1 列 16）同理。其余无图标格抽查的缩略图都像真实地块，但没有逐格看大图。

## 第三轮：可疑问题校对

### 空白格

- 6-10 行 5 列 1：放大目测是背景纸张，不是格子，已从 `maps.json` 删除；自动规则无法把它与第 7 章米色空白格区分，所以记入 `manual_fixes.json`，`tools/build_map_data.py` 重建时会再次应用。
- 7-6 行 1 列 16：放大目测是真实空白格，保留。

### 事件对应规律（修正前两轮的结论）

把事件按名字分组再对照专属格，发现比前一轮更干净的规律，并**撤回**前面关于孕育之母、入学仪式的推断：

| 规律 | 依据 |
| --- | --- |
| 有红色血肉格 ⇔ 该图有「血污之池」事件 | 19 张图两者同时出现，其余 67 张两者都没有，无例外 |
| 有审查会探员格 ⇔ 该图有「监察点」和「审查会探员」事件 | 10 张图完全重合，无例外；有 2 个探员格的图也只有这一对事件 |
| 其余事件数 = 事件格数 | 103 张有关联事件的图里 100 张吻合（第 1、3、4、6、7、8、9 章和全部特殊活动逐图吻合） |

撤回：第 7 章多出的那条事件其实是「血污之池」（第 7 章几乎每张图都有红色格），不是孕育之母；入学仪式在维基事件列表里没有对应条目。所以 7-15（没有红色格）、8-4 都不再是例外。孕育之母已改为功能不明。

血污之池的选项多为「呼唤唤醒体 / 奋力挣扎 / 插入银钥匙」（11 次），也有只有前两项（8 次）和「吸收血池」（1 次）的版本。监察点的选项在 10 张图里都是「离开 / 诈降 / 闯入」。

### 仍对不上的 3 张图

- **5-3**：多出的「未知」是调试占位图（`UI_Dbgcopy_Image_MAP_009`），不对应地图格，实际吻合。
- **2-8**：多出的「亮晶晶」与该图析出点的标签同名，疑似该图的析出点就是事件格；其他图的析出点没有这个规律。
- **2-10**：3 个事件格对应 2 条维基事件，且关联是按章节推断（`chapter_inferred`）。目测确认 3 个事件格都是真实的，所以更可能是维基该关卡少记了一条事件，没有证据能证实。

这些规律来自逐图对照，没有实机验证；同一张图里多个红色格是否各自触发一次事件也不明。
