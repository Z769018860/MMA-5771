## 5-11：已解决

原因：起点被两扇锁门（1,7）、（2,10）围住，唯一不用开门的出路是西南方的一块裂纹石（2,8），它被邻格完全包围，被「地块在黑色迷雾里」的判定误排除，于是起点区域只剩 2 格，钥匙在门后，路线判不可达。

修复：`classify_site` 对已有 ≥2 个已知邻格的位置不再要求周围有迷雾；紫蓝格仍要求在迷雾内（否则蓝色背景会被误认成 19 格紫蓝格，已在 8-11、9-12 上验证并避免）。

结果：新增 3 格裂纹石，5-11 路线为 起点 → 裂纹石 → 战斗 → 战斗 → 裂纹石 → 精英 → 裂纹石 → 联络点 → 事件 → 锈蚀钥匙 → 单行密道 → 密道出口 → 联络点 → 最终战。同一改动还补出另外 22 张图的 1–4 格（多为裂纹石、个别空白格和红色格），共新增 34 格，`maps.json` 现为 2887 格。目测 5-11 与 6-2 的新增格位置正确，其余未逐一检查。
