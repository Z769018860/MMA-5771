# 忘却篇地块类型（网络检索汇总）

来源为搜索引擎对游戏介绍页的摘要，只有名称和一句话功能，未逐格实机核对。灰机维基、B 站、TapTap、Steam 页面都读不到详情（Cloudflare 拦截、验证码或内容不含此项），所以各章节的事件选项没有取得。

主线按蜂窝状六边形格子探索，视野为 1 格，未探索格被迷雾遮盖。除普通可走格外有 10 种特殊格：

| 地块 | 功能（摘要） | 对脚本的含义 |
| --- | --- | --- |
| 剧情格 | 触发剧情推进 | 进入后走 Story 对话流程 |
| 事件格 | 触发带选项的特殊事件 | 读取标题和选项，记录代价（见 8-2 已核对事件） |
| 战斗格 | 战斗，分普通 / 危险 / Boss 三档 | 进入阵容和战斗流程 |
| 物资格 | 拾取局内外货币、钥匙 | 优先收集，钥匙用于门锁格 |
| 商店格 | 用局内货币购买增益，或出售卡牌 | 目前不自动购买 |
| 驱雾格 | 扩大视野范围 | 可用于揭开更多候选格 |
| 幻象格 | 通过需要付出感染症状作代价 | 默认不主动进入 |
| 门锁格 | 阻挡通行，需钥匙解锁 | 持有钥匙且可达时才尝试（实机已验证「锈蚀钥匙」） |
| 通道格 | 定向传送 | 传送后必须重建当前格和邻格 |
| 援助格 | 恢复生命，或唤醒一名角色 | 低血量时优先 |
